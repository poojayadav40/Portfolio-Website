# 🌐 Personal Portfolio Website

A personal portfolio website showcasing my projects, skills, and background. 

🚀 **Live Demo:** [poojayadav40.github.io/Portfolio-Website](https://poojayadav40.github.io/Portfolio-Website/)

---

## 📌 Features

* **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.
* **About Me Section:** An overview of my background, education, and interests.
* **Featured Projects:** Highlights of my work with links to code repositories and live demos.
* **Skills Showcase:** Breakdown of technical tools, programming languages, and frameworks.
* **Contact Form:** Easy ways for recruiters and visitors to reach out.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Icons & Fonts:** Font Awesome / Google Fonts
* **Hosting:** GitHub Pages

---

## 💻 Local Setup & Development

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/poojayadav40/Portfolio-Website.git](https://github.com/poojayadav40/Portfolio-Website.git)
2. Navigate to the project directory:
   cd Portfolio-Website
3. Open the project:
   Simply open index.html in your web browser, or use VS Code's Live Server extension.
